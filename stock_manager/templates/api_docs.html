REST API Documentation (v1)

Standardized JSON API endpoints for programmatic inventory, invoicing, CRM, and stock management.

Barcode Scanner
Authentication & Headers

All API endpoints require the X-API-Key HTTP request header. Set via environment variable API_KEY.

Current API Key: {{ api_key }} Active
curl -H "X-API-Key: {{ api_key }}" http://localhost:5000/api/v1/products

1. Products API

GET /api/v1/products
Filter: ?sku=<value>

List all products with categories, suppliers, and tags. Optionally filter by exact or partial SKU.

Example Response (200 OK):
[
  {
    "id": 1,
    "name": "Mechanical Keyboard",
    "sku": "KB-100",
    "quantity": 25,
    "price": 89.99,
    "category_name": "Electronics",
    "supplier_name": "Tech Corp",
    "tags": ["Bestseller", "New"]
  }
]
GET /api/v1/products/<id>

Retrieve single product details by integer ID.

{
  "id": 1,
  "name": "Mechanical Keyboard",
  "sku": "KB-100",
  "quantity": 25,
  "price": 89.99,
  "category_name": "Electronics",
  "supplier_name": "Tech Corp",
  "tags": ["Bestseller"]
}
POST /api/v1/products

Create a new product. Stock is allocated to the default warehouse.

Request Body (JSON):
{
  "name": "Wireless Mouse",
  "sku": "MS-200",
  "quantity": 50,
  "price": 29.99,
  "category_id": 1,
  "supplier_id": 1
}
Response (201 Created):
{
  "id": 2,
  "name": "Wireless Mouse",
  "sku": "MS-200",
  "quantity": 50,
  "price": 29.99,
  "category_name": "Electronics",
  "supplier_name": "Tech Corp",
  "tags": []
}
PUT /api/v1/products/<id>

Update product attributes (name, sku, price, category_id, supplier_id, quantity).

// Body: { "price": 27.99, "name": "Wireless Ergonomic Mouse" }
// Response 200 OK: Updated product object
DELETE /api/v1/products/<id>

Permanently remove a product record and clean up associated image uploads.

{ "message": "Product deleted", "id": 2 }

2. Customers API (CRM)

GET /api/v1/customers

List all customers with contact details and lifetime spent total.

[
  {
    "id": 1,
    "name": "Alice Johnson",
    "email": "alice@acme.com",
    "company": "Acme Corp",
    "status": "active",
    "total_spent": 1250.00
  }
]
GET /api/v1/customers/<id>

Get customer profile along with their invoice transaction history.

{
  "id": 1,
  "name": "Alice Johnson",
  "email": "alice@acme.com",
  "company": "Acme Corp",
  "status": "active",
  "total_spent": 1250.00,
  "invoices": [
    { "id": 1, "total_amount": 1250.00, "date": "2026-11-06", "currency": "USD" }
  ]
}
POST /api/v1/customers

Create customer. Sends welcome email if email is provided.

// Body: { "name": "Bob Smith", "email": "bob@example.com", "company": "Beta LLC", "status": "lead" }
// Response 201 Created
PUT /api/v1/customers/<id>

Update customer contact and status attributes.

{ "message": "Customer updated", "id": 2 }

3. Invoices API

GET /api/v1/invoices

List all invoices with client, total, currency, and discounts.

[
  {
    "id": 1,
    "client_name": "Alice Johnson",
    "date": "2026-11-06T14:30:00",
    "total": 1250.00,
    "currency": "USD",
    "discount_pct": 5.0
  }
]
GET /api/v1/invoices/<id>

Retrieve detailed invoice with line items.

{
  "id": 1,
  "client_name": "Alice Johnson",
  "customer_id": 1,
  "date": "2026-11-06T14:30:00",
  "subtotal": 1315.79,
  "discount_pct": 5.0,
  "total": 1250.00,
  "currency": "USD",
  "currency_symbol": "$",
  "items": [
    {
      "product_id": 1,
      "product_name": "Mechanical Keyboard",
      "quantity": 10,
      "unit_price": 89.99,
      "total_price": 899.90
    }
  ]
}

4. Stock & Inventory Management API

GET /api/v1/stock/low

Fetch all items with total quantity ≤ 10 across warehouses.

[
  {
    "id": 3,
    "name": "USB-C Cable",
    "sku": "CAB-01",
    "quantity": 3,
    "price": 9.99,
    "status": "critical"
  }
]
POST /api/v1/stock/adjust

Increment or decrement stock for a product in the primary warehouse.

Request Body (JSON):
{
  "product_id": 1,
  "adjustment": 10
}
Response (200 OK):
{
  "message": "Stock adjusted successfully",
  "product_id": 1,
  "adjustment": 10,
  "new_quantity": 35
}
