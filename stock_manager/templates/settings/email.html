Configuring via Environment Variables

StockFlow loads email settings from environment variables upon startup. To update live server parameters, configure the following environment variables:

MAIL_SERVER="smtp.gmail.com"
MAIL_PORT=587
MAIL_USERNAME="your-email@gmail.com"
MAIL_PASSWORD="your-app-password"
MAIL_DEFAULT_SENDER="noreply@stockflow.com"
If SMTP is unconfigured, StockFlow fails gracefully with clear warning messages without disrupting business operations.
