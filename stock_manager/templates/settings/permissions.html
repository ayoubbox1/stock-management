Admin Administrator

Full system access with wild-card ('all'). Can manage users, assign roles, configure SMTP, view and control APScheduler jobs, edit permissions, and delete any resource.

Manager Store / Operations Manager

Can view all records, create and edit inventory, delete products and customers, view analytics reports, receive purchase orders, approve/reject customer returns, and export CSVs.

Staff Frontline Staff

Can view products, create new invoices, record customers, scan barcodes, and export data. Cannot delete critical records, view executive analytics, manage system settings, or approve refunds.
